# S7 Affinity — 24 questionnaire icons

Vector SVG icon set for the 24 S7 Affinity questions.

## Visual system

- ViewBox: `0 0 24 24`
- Default display size: `48 × 48 px`
- Stroke: `currentColor`
- Suggested gold: `#C99632`
- Suggested navy: `#0A2A5E`
- Stroke width: `1.6`
- Rounded line caps and joins
- Each SVG includes a French `<title>` and `aria-label`

## React / Next.js usage

```jsx
<img
  src="/icons/s7-affinity/06-core-values.svg"
  width={48}
  height={48}
  alt="Valeurs essentielles"
/>
```

For CSS-controlled colour, import the SVG as a component through SVGR and set `color`.
